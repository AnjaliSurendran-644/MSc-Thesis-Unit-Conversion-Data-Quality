# MSc Thesis – Unit Conversion and Data Quality

## Overview

This repository contains experimental code developed as part of my Master's Thesis at Uppsala University.

The research investigates how repeated unit conversions can affect numerical accuracy and data quality in software systems.

## Technologies

- Python
- NumPy
- F#
- Pint
- Data Analysis

## Example Experiment

This experiment evaluates error propagation caused by repeated conversions between km/h and mph using float32 precision.

## Research Focus

- Numerical Accuracy
- Data Quality
- Unit Conversion
- Floating Point Precision
- Software Reliability
